# Changelog — Smart Attendance System Multi-Tenant SaaS

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-11-22
### Added
- Multi-Tenant dual-track SaaS engine supporting Educational Institutions and Corporate Multi-Branch Offices.
- Role-Based Access Control (RBAC) across Super Admin, Tenant Admin, Teachers, Employees, and Receptionists.
- High-precision biometric, QR code, and manual kiosk attendance clocking with geofencing.
- Institution curriculum hierarchy: Classes, Sections, Subjects, and Teacher-Subject mapping.
- Office multi-location branch management with customizable work schedules and break time thresholds.
- Tiered SaaS subscription billing models with automated seat and quota enforcement.
- Automated GitHub Actions showcase documentation synchronization pipeline.
